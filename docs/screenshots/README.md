# 预留的产品界面截图

本目录用于存放 **真实产品窗口** 截图。当前尚未放入 PNG，因为仓库与本机工作区都没有可用的产品界面截图。

**请勿**提交 AI 生成图、编造界面或装饰性插图。

## 建议启动（Linux 或 Windows 桌面）

```bash
npm install
npm run dev
```

需要 Node.js 与可运行的 Electron（`electron-vite dev`）。本地规则引擎可离线演示；若打开设置或远程引擎页面，请遮盖 API Key。合同样例请使用非敏感数据，或在截图中遮盖对方名称、金额等。

## 建议截取并使用的文件名

| 文件 | 预期画面 |
| --- | --- |
| `01-workbench.png` | 主工作台：合同列表或全生命周期阶段总览 |
| `02-extract-or-detail.png` | 合同详情，或要素提取结果 |
| `03-review-or-approve.png` | 审核或审批界面 |

截取后把上述文件放到本目录，并保持 README 中的相对路径不变，再追加提交到同一文档分支。
